# ОКНО · Вектор-9

3D киберпанк стелс-головоломка: устранить цель, прыгая по времени внутри закрытого интервала 14:00–22:00.
Мир живёт по детерминированным правилам; любое вмешательство каскадом меняет последствия (эффект бабочки).

## Запуск
```bash
npm install
npm run dev      # разработка (http://localhost:5173)
npm test         # тесты симуляции (Vitest)
npm run build    # статичный dist (GitHub Pages: .github/workflows/pages.yml, ветка master/main)
```

## Управление
- **WASD** — движение, **Shift** — бег, **Пробел** — прыжок, **мышь** — камера (можно смотреть вверх)
- **E / F / G / H / J** — контекстные действия (взять, отдать, говорить, действия миссии)
- **Q** — «Окно» времени: шкала, выбор момента, предмет для переноса, **Enter** — прыжок. Назад откатывается весь мир и вы сами (позиция в тот момент); с вами остаются знания и один предмет
- **Tab** — журнал аномалий (дерево причин) и знания · **N** — карта · **1–5** — скорость x1…x16 · **M** — звук
- **Esc** — меню: язык RU/EN, звук, качество графики, рестарт с точки 0
- **ЛКМ** — выстрел в того, кто под прицелом (кружок в центре экрана; курсор захватывается кликом по сцене). Пистолет тихий (поднимет тревогу, только если рядом свидетели), винтовка громкая. Для идеального устранения: винтовка с щита у моста в окне 21:34 (действие «Выстрелить в Лаша»)
- **V** — сесть в припаркованную машину / выйти; в машине W/S — газ/тормоз, A/D — руль, Shift — нитро, Пробел — ручник
- **T** — такси к ключевым местам (за игровое время) · **U** — использовать предмет (стим, еда) · **K** — навыки
- Магазины (лапшичная, «Импланты 24/7», ломбард, бар) — заходите внутрь, **E — торговать**: покупка имплантов (бонус к навыкам в диалогах), продажа найденного лома
- **Навыки** как в Disco Elysium: опыт за успешные проверки, новые факты и знакомства; 3 опыта = очко навыка (K). Голоса навыков в диалоге звучат, только если навык ≥ 4. Проваленная проверка закрыта, пока навык не вырастет
- **Обучение** — кнопка на стартовом экране
- Диалоги: **Пробел** — дальше, **1–9** — выбор ответа; проверки навыков детерминированы (навык + доверие ≥ сложность)

## Что готово
- Детерминированная симуляция (`src/sim`): расписания, маршруты по улицам (пешком/авто/трамвай №7), причинный журнал, снимки раз в минуту, прыжки, предметы-путешественники (один слот, правило двойника)
- Каскад «проездной» возникает сам из общих правил; вся миссия: идеальный путь (3 вынужденных прыжка), 2 решения, провал при пропуске любого шага — тесты
- ~170 жителей из 25 архетипов, полиция, новости «Вектор-24» из состояния мира, Наниматель, эхо стёртых веток
- Диалоги-деревья с голосами навыков, проверками, доверием, фактами (`tools/gen_dialogues.py` → `src/data/dialogues.json`)
- Город: сетка улиц с полосами, зебрами и тротуарами, кварталы по районам (даунтаун-небоскрёбы, центр, спальные панельки, промзона), процедурные фасады, витрины, неоновые вывески, рекламные щиты, светофоры (работают и гаснут в блэкаут), фонари, скамейки, автоматы, деревья, провода, река и вантовый мост, трамвайная сеть, кольцевой дом-улей, башня «Гелион» с голограммой
- Машины по полосам (останавливаются на красный), припаркованные машины, кортеж, такси, полиция, летающий транспорт, дроны
- Люди с анимацией ходьбы, зонтами под дождём, рабочими движениями
- Отражения мокрого асфальта (процедурная карта окружения), дождь, молнии, bloom/ACES/хроматическая аберрация
- Звук синтезом, RU/EN

## Известные проблемы
- Ассетов нет: всё процедурно; производительность зависит от GPU (в меню есть «низкое» качество)
- Прыжок вперёд на несколько часов блокирует UI на 1–2 с
- Машины фонового трафика не взаимодействуют с пешеходами
