# «Окно» — мини-уровень «Часовая набережная». Полная спека v2

> Это ТЗ для облачной сессии. Все ассеты в `[квадратных скобках]` существуют в `assets/models/` (путь `[папка/имя]` = `assets/models/папка/имя.glb`). Если в скобках стоит `(код)` — вещь строится кодом из кусков пака, готового файла нет.
> Цифры (времена, давления, скорости) — **стартовые значения**. Инварианты (что должно получиться) важнее цифр: подгоняй цифры тестами из раздела 11.

## 0. Что это и зачем

Небольшой, но красивый и связный вертикальный срез: **одна ночь, одна набережная, 40 минут игрового времени, 3–5 минут на первое знакомство, 25–35 минут реального прохождения.** Цель — «ВАУ» с первого кадра (мокрая ночь, газовые фонари, туман, отражения) и ощущение, что мир живой: у каждого NPC своя цель, и от маленького сдвига рушится вся ночь.

Старая ветка `claude/sweet-davinci-1ym3mj` (репо `okno`): рабочее ядро, но визуально и по живости — плохо. Берём оттуда **только** симуляцию/дневник/диалоги-движок/локализацию, всё остальное (визуал, мир, NPC, контент) переписываем по этой спеке.

## 1. Сюжет в трёх актах

**Место.** Портовый город, набережная Часовой башни, ночь перед Праздником Фонарей. Дождь, туман, мокрая брусчатка. Тёплые газовые фонари против холодной воды.

**Герой.** Ученик часовщика (модель `[characters/hero_rogue_hooded]`). Имя — «Ученик» (в Ru), «Apprentice» (En). Он единственный, кто умеет смотреть в **Окно** — циферблат-линзу на верху башни, которая показывает мир на двух метках: **T0 = 21:20** (начало ночи) и **T1 = 22:00** (момент праздничной церемонии).

**Акт I (21:20–21:40) — «Обычный вечер + урок ключа».** Игрок видит живую набережную, знакомится с Окном, получает урок «ключ стража» (раздел 13). Маленькая завязка: у скамьи на трамвайной остановке лежит **проездной** швеи Тильды. Игрок может его взять, но не обязан. Всё остальное мир сделает сам.

**Акт II (21:40–22:00) — «Пожар».** Если ничего не менять, к 21:58 в таверне «Три якоря» загорается кухня, к 22:00 горит полтаверны, на доске «Вестник» — экстренный выпуск. Игрок видит это при первом дойти-до-T1 или при прыжке вперёд.

**Акт III — «Распутать нить».** Через Журнал и «Хронику Окна» (граф причин) игрок узнаёт, что пожар вырос из пяти мелочей, начавшихся с потерянного проездного. Дальше — выбор из нескольких решений (раздел 12) и концовки (раздел 15).

Главное: **цепочка «проездной → пожар» нигде не прописана**. Она получается из общих правил (раздел 10).

## 2. Железные правила (всё, о чём договорились раньше)

### 2.1 Время и прыжки
- Окно времени **[T0, T1]** = 21:20–22:00 (2400 игровых секунд). Масштаб по умолчанию: **1 реальная сек = 4 игровые сек** (всё окно ≈ 10 минут «чистого» реала).
- **Только ускорение времени.** Нет паузы, нет замедления. Меню/дневник не останавливают симуляцию «в мире», но игровые часы ставятся на паузу автоматически только в диалоговом UI (диалог сам стоит игровое время, см. ниже), в остальных меню — нет. (Мягкое правило, как в старой ветке — не ломай существующее поведение.)
- **Диалог и перемещение стоят игрового времени:** реплика ≈ 6 игр. сек; выбор варианта ≈ 15 игр. сек; навык-проверка ≈ 10 игр. сек. Ходьба — физически по скорости.
- **Прыжок назад** (в T0 или в запомненный снимок): мир восстанавливается из ветки/снимка, **все более поздние действия стираются**. Остаётся только то, что разрешено правилом переноса (2.2).
- **Прыжок вперёд:** мир пересчитывается детерминированно от точки с учётом всех записанных вмешательств игрока.
- Кнопка Окна работает только у Окна (башня). Прыжок стоит 30 игр. сек «на раскрутку» (игра честно сжигает время анимацией Окна).

### 2.2 Что переносится через прыжок
- **Знания** (журнал, «нити» между записями, подтверждённые факты).
- **Ровно один предмет** (слот «Карман Окна»). Правила:
  - **Сохранение предмета:** если оригинал ещё есть в мире на момент прибытия, то он **исчезает в момент T** — в тот самый момент, когда в прошлой ветке игрок его забрал. У игрока в руках — «двойник». Пока оригинал существует, **двойник нельзя нести дальше** (через ещё один прыжок) и нельзя отдать NPC навсегда; он «мерцает».
  - **Прикреплённые («anchored») предметы** (прибиты/привинчены/залиты) нести нельзя вообще.
  - NPC, которые заметили пропажу оригинала в момент T, реагируют по обычным правилам (искать, обвинять, паниковать).

### 2.3 Детерминизм
- Симуляция — чистый TypeScript без THREE. Один и тот же `seed + список вмешательств` даёт один и тот же **хэш состояния** на каждый тик. Никакого `Math.random()`/`Date.now()` в `src/sim`. Генератор — сидированный (xoshiro/PCG), потоки раздельные для подсистем.
- **Никакого LLM внутри игры.** Диалоги — граф реплик (JSON), проверки навыков — детерминированные (раздел 9.4).

### 2.4 Локализация
- Ru/En, переключатель в настройках и на титульном экране. Все строки — ключи (`dlg.ignat.hello`), без хардкода. Интерфейсные шрифты: `[assets/fonts]` (Playfair/Old Standard для заголовков, Spectral/PT Serif для текста, IBM Plex Mono для чисел, Marck Script для рукописных записок). Все кириллические.

### 2.5 Аномальный журнал («Хроника Окна»)
- Граф причин: каждое событие симуляции пишется `{id, t, type, actors, cause: [id...]}`. Вмешательства игрока — события-корни.
- **Baseline-diff:** при каждом возврате в T0 запоминается «естественный» прогон без вмешательства. Хроника показывает отличия: чего не было бы, если бы не игрок.
- **Значимость** события = `охват (сколько акторов затронуто) × глубина (длина следствий) × вес типа (смерть/пожар > задержка > болтовня)`. На экране — отсортированный список аномалий + кнопка «показать цепочку» (подсвечивает путь на карте и в графе).
- Цепочка раскрывается игроку только по **виденным** звеньям (флаг `witnessed`). Видел звено — оно в Хронике, не видел — «?».

### 2.6 Что обязательно проверяется тестами (раздел 11)
- Решаемость: **≥ 3 прыжка** нужно кратчайшему решению (включая урок ключа), **≥ 2 независимых решения**.
- Эмерджентность каскада «проездной» (раздел 10).
- Хэш-детерминизм.

## 4. Эстетика (рецепт «красиво», проверен на `tools/style_test`)

1. **Тон.** Холодная синяя ночь + тёплые янтарные точки. Контраст фонарей и тумана — это 70% «ВАУ».
2. **Свет.** Лунный `DirectionalLight` (тени, 2048), полусфера, `ACESFilmic`, `FogExp2 ≈ 0.034` цвета `0x101a2e`. `PointLight` на каждом фонаре (не более **12 активных** за кадр — culling по расстоянию до камеры), мерцание, спрайт-ореол `[textures/procedural/lamp_halo]`, эмиссивная лампа. Окна: `[textures/procedural/window_warm_emissive]` на плоскостях за стеклом.
3. **Пост-обработка.** Bloom (0.75/0.7/0.82) → грейд (бирюзовые тени, янтарные света) → виньетка → зерно `[textures/procedural/film_grain]`.
4. **Земля.** Мокрая брусчатка `[textures/procedural/cobble_*]` (repeat ≈ 34 на 60 м), на набережной — `[textures/procedural/pavers_*]`, на причалах — `[textures/procedural/planks_*]`. Лужи — тёмные диски с низким roughness, кольца ряби `[textures/procedural/ripple_ring]`.
5. **Дождь.** LineSegments + капли-кольца на лужах; не ночь без дождя. Интенсивность связана с `weather` (можно ослабить к 22:00).
6. **Туман.** Объёмный `FogExp2` + слои спрайт-дыма `[particles/smoke_white_puff/*]` у воды и в переулках.
7. **HDRI.** `[hdri/night_512.exr]` как `scene.environment`, интенсивность ≈ 0.35 (запасные: `[hdri/venice_512.exr]`, `[hdri/dawn_512.exr]`).
8. **Вода.** Плоскость с шейдером (код): тёмная, мелкая рябь, отражение фонарей (fake через зеркальную плоскость низкого разрешения или SSR-лайт).
9. **Масштабы.** Кит города ×1.4, hex-здания ×2.3, мини-NPC ×1.35, герой ×0.62 (подтверждено рендером).
10. **Окружение.** Холмы, деревья, мельницы — фон в тумане. Никаких пустых «серых» мест: каждый кадр вокруг игрока ≥ 6 разных пропсов.

Обязательный чек-лист «красиво» (раздел 16): 3 скриншота (площадь, набережная, интерьер таверны) должны выглядеть не хуже `docs/screenshots/proof_*.png`.

## 5. Здания и интерьеры (всё интерактивное)

Правила для всех интерьеров:
- **Бесшовный вход:** без экранов загрузки. Интерьер уже в сцене. При входе в зону двери (триггер) крыша и фасадная стена плавно прозрачнеют (0.25 с, dither), включается внутренний свет, наружный дождь глушится (фильтр звука).
- Каждая дверь: `[town_kit/wall_door]` / `[town_kit/wall_doorway_square]`, состояния {открыта, закрыта, заперта}, звук `[audio/rpg_foley/door_open_1]`, `door_close_*`. Запертая — нужен ключ-предмет или проверка «Ловкость рук».
- Каждый предмет мебели — **объект симуляции** (позиция, владелец, состояние), а не декор. Перечень «Глаголы» — какие действия доступны (Осмотреть / Взять / Открыть / Сесть / Спрятаться / Включить / Передвинуть).
- Освещение интерьера: 1–3 `PointLight` на комнату, свечи/камины мерцают; тень только у главного света комнаты.

Обозначения: **О** осмотреть, **В** взять, **Откр** открыть/закрыть, **С** сесть, **Сп** спрятаться, **Вкл** включить/потушить, **П** передвинуть, **Г** говорить.

### 6.2 «Живая» психология (минимум)
Каждый NPC — агент с **потребностями** (голод, усталость, долг, любопытство), **целями** (из расписания и событий), **памятью** (что видел, что слышал) и **эмоцией** (спокоен/спешит/испуган). Utility-AI: выбор действия = max(полезность). Полезность учитывает дедлайны и препятствия. Сюда же — «болтовня на ходу» (barks: короткие реплики над головой по триггерам: дождь, шум, лужи).

## 8. Системы симуляции (правила, из которых растёт каскад)

### 8.1 Время и расписание
- `tick = 0.5 игр. сек`. Мир: `Time`, `Weather`, `Lamps`, `Doors`, `Tram`, `Dock`, `Gas`, `Fire`, `NPC`.
- NPC планируют маршрут A* по сетке 0.5 м + динамические препятствия (бочки, повозки, закрытые двери, огонь).
- Потребность «быть к дедлайну»: если `ETA > deadline`, ищет более быстрый вариант (транспорт, короткий путь); если не успевает — **сжимает план** (пропускает низкоприоритетные шаги), что и приводит к ошибкам (см. Матвей).

### 8.2 Газ, давление, огонь
- **Сеть:** газгольдер → шкаф КШ-1 → магистраль вдоль набережной → ответвления: фонари (×10), таверна (кухня), мастерская (лампа).
- Состояние: `P_net` (бар), `P_nominal = 1.0`. Вентиль подачи (положение 0…1) повышает до `P_target = 1.0 + 1.6·valve`. Вентиль стравливания снижает **0.05 бар/мин** при полном открытии.
- **Рейтинги стыков:** каждый стык имеет `rated` (бар). Фонари — 3.0; кухня таверны — **2.0 (старый)**. Если `P_net > rated` → стык «течёт» со скоростью `k·(P_net − rated)`.
- **Концентрация газа** в клетках 1 м³: диффузия + вытяжка + окно + дверь. Порог ощущения запаха NPC: 0.5%. Порог зажигания: **5%**.
- **Огонь:** источник = очаг, свеча, печь, духовка, факел, фонарь с живым пламенем. Если в клетке с источником `gas ≥ 5%` → **вспышка** → пожар (горит мебель, растёт, дым, тепло, повреждает NPC в 2 м).
- Влияние давления на фонари: яркость ∝ `clamp(P_net/1.0, 0.2, 1.1)`, при `P_net < 0.6` фонарь мерцает — **Игнат замечает** и идёт к шкафу.
- Кошка: любит тёплое; в 21:56 запрыгивает на плиту и может столкнуть свечу (правило «объект на краю + анимация → падает») — тоже источник. Это второй возможный фитиль, не обязателен.

### 8.3 Трамвай
- Расписание, вместимость, продажа/проверка проездного: `board(npc)` разрешён, если `has(pass) ∨ has(ticket)` и `seats>0`. Кондуктор проверяет у посадки. Отказ → NPC перепланирует (ждать / идти / купить).
- Игрок тоже подчиняется правилам (билет, проездной, безбилетник — Хладнокровие/Убеждение).
- Если игрок отнял проездной, пока NPC-владелец не успел его подобрать, **правило не знает, что это «сюжет»** — оно просто видит: нет проездного.

### 8.4 Причал и семафор
- `Dock.decide(barge, t)`: на отметке **21:42** Борис смотрит на мачту. Если нет сигнала закрытия (красный над синим) → швартуется к причалу 2 и **выгружает груз** на набережную (бочки как динамические препятствия, закрывают проход).
- Если сигнал есть — отходит на рейд до конца праздника.

### 8.5 Восприятие и стелс
- Зрение: конус ±55°, дальность `r = 12 · (0.4 + light)`; свет — из фонарей/окон. Звук: шаги по материалам (громкость по поверхности: плиты — громко, трава — тихо; `crouch` — тише); дождь маскирует.
- Заметил → реакция по должности: страж — окрик, предупреждение; Агата — крик.
- Всё детерминированно (без RNG).

### 8.6 Приказы «буквально»
- Игрок может **командовать** (через диалог) NPC, у которых есть к нему доверие/долг: «Открой вентиль», «Закрой». NPC исполняет **буквально**, без домысливания. «Закрой вентиль» → ближайший вентиль, тот, что в видимости. Это решение C (раздел 12) и источник комедийных поворотов.

### 8.7 Эскорт и эвакуация
- Ребёнок (Пип) следует за игроком, **только если держит за руку** (состояние `escort`), скорость ограничена; в пожаре Пип прячется (ужас) и не выходит без эскорта.
- **Протокол эвакуации:** по сигналу тревоги (крик Агаты/колокол) NPC в здании идут к ближайшему выходу, обходя огонь; если путь отрезан — окно/второй выход. Игрок может **организовать** эвакуацию: открыть двери, убрать препятствия, вывести Пип.

## 9. Диалоги и проверки

### 9.1 Формат
JSON-граф: узлы {говорящий, текст-ключ, варианты, условия, эффекты, стоимость-времени}. Вариант может иметь **условие знания** (виден, только если игрок знает K#), **проверку навыка** и **стоимость**. Объём: **≈ 20–25 NPC-диалогов, ≈ 350 реплик** суммарно на 12 NPC (по 15–35 реплик на NPC + 40 реплик «баркoв»). Пишутся сразу в Ru, перевод En — параллельно.

### 9.2 Навыки (в духе Disco Elysium)
**Наблюдательность, Техника, Убеждение, Эмпатия, Хладнокровие, Ловкость рук, Память, Авторитет.** Начальное значение 4–7; бонусы от знаний (+1/+2) и предметов.

### 9.3 Голоса навыков
Короткие реплики-«вставки» от навыков (Память подсказывает дату, Эмпатия — чувства NPC, Техника — что с трубой). Они выпадают из контекста: при осмотре объекта показываются реплики навыков, у которых хватает уровня.

### 9.4 Детерминированная проверка
`успех ⇔ skill + бонусы ≥ сложность` (без костей). Показывается шанс-«порог» (например «Убеждение 6, нужно 7»). Провал — **последствие**, а не тупик: NPC запоминает, цена в игр. времени, можно попробовать позже при ином навыке/знании.

### 9.5 Примеры (Ru/En)
**Игнат (ворота), первый контакт.**
- Игнат: «Стоять. Согласно уставу, до праздничного фонаря вход закрыт.» / “Halt. By regulation, entry is closed until the lantern lighting.”
  - [Наблюдательность 5] «Ключ у вас на поясе, а крюк в будке пуст.» (ключ → знание K4) / [Observation 5] “The key is on your belt, the hook in the booth is empty.”
  - [Убеждение 7] «Мне нужно к башне — там часовщик ждёт.» / [Persuasion 7] “I need to reach the tower — the watchmaker is waiting.”
  - «Понял.» (выход).

**Тильда (мастерская/остановка).**
- Тильда: «Тяжёлое. Но я справлюсь.» / “It’s heavy. I’ll manage.”
  - [Эмпатия 5] «Вы торопитесь не из-за флага. Что-то случилось?» / [Empathy 5] “You’re not hurrying because of the flag. What happened?”
  - [Помочь] «Давайте я возьму.» (если свободны руки) → эскорт-перенос свёртка (дорого по времени).
  - [Дать билет] (если есть) → бонус доверия.

**Матвей (фонарщик).**
- Матвей: «Три приёма: сорок, семьдесят, сто. Слишком быстро нельзя — трубы старые.» / “Three steps: forty, seventy, hundred. Too fast won’t do — the pipes are old.”
  - [Память 6] «Журнал: “Не открывать сразу >70%”.» (знание K5)
  - **Приказ** (если доверие ≥ 2): «Не открывай, пока я не скажу.» → исполняется **буквально**.

**Пип (ребёнок).**
- Пип: «Не скажу, что у меня в сундучке.» / “I won’t tell what’s in my chest.”
  - [Эмпатия 4] «Тебе что-то нужно взамен?» → торг: блестящая монета/кружка → Пип отдаёт проездной.
  - [Авторитет 8] «Верни. Сейчас же.» → сработает, но снизит доверие.

## 10. Эмерджентная цепочка «проездной» (НЕ скриптовать)

**Принцип:** нет события `PIP_STEALS_PASS → …`. Есть общие правила (раздел 8) и стартовое состояние. Цепочка получается из них. Это проверяется тестом.

**Стартовое состояние (T0):**
- Проездной Тильды лежит на скамье остановки «Площадь» (она оставила его, когда завязывала шнурок/поправляла свёрток).
- Тильда выйдет из дома в 21:24; на остановке она сначала **проверяет карманы и рядом лежащие предметы** (правило «ищу нужное в радиусе 3 м»).
- Пип (любопытство, «блестящее») бродит в радиусе остановки; правило: ребёнок подбирает «интересные мелкие предметы» в 3 м, если взрослые не смотрят.

**Ожидаемый ход без игрока (baseline):**
1. 21:23 Пип подбирает проездной.
2. 21:27 Тильда у скамьи — проездного нет. Кондуктор не пустит без билета; билет 2 монеты, у неё 1 монета → кроме того, свёрток тяжёлый (правило: *тяжёлая ноша → не бросать скамью, идти вдоль, отдыхая*).
3. 21:30 Трамвай уезжает без неё.
4. 21:31 Тильда идёт пешком (скорость 0.5 м/с, привалы), 21:40 приходит в бюро.
5. 21:42:30 Орвен получает флаг и **поднимает сигнал закрытия** — позже порога Бориса (21:42).
6. 21:42 Борис не видит сигнал → швартуется к причалу 2, выгружает бочки на набережной (21:46); они блокируют основную дорожку.
7. 21:48 Матвей выходит из таверны, до шкафа КШ-1 по набережной не пройти → обход через двор таверны и церковный проулок (+80 м) → приходит в 21:53:30.
8. Дедлайн «фонари к 22:00» + 3 приёма по 2 минуты = 6 минут > 6.5 мин остаток? Утилити даёт: **сжать план**, открыть вентиль сразу на 100% (пропустить приёмы).
9. 21:54 давление скачет до ~2.6 бар (при `P_nominal=1.0` и полном открытии). Стык кухни (рейтинг 2.0) начинает течь.
10. 21:56 Агата чувствует запах (>0.5%), открывает окно (замедляет рост), но кошка и очаг…
11. 21:58 концентрация у плиты ≥ 5% → вспышка от конфорки/очага. 21:59 пожар. 22:00 (T1) — «Вестник»: «Пожар в таверне».

**Что должен проверять тест `sim:cascade`:**
- Если на старте убрать проездной со скамьи ИЛИ вернуть его Тильде до 21:27 — пожар **не происходит** (при прочих равных).
- Граф причин содержит путь `проездной ← … ← пожар` из событий общих типов (`PICKUP`, `BOARD_DENIED`, `WALK_STARTED`, `SIGNAL_RAISED`, `DOCK_DECISION`, `OBSTACLE_PLACED`, `PATH_REPLANNED`, `PLAN_COMPRESSED`, `PRESSURE_SPIKE`, `JOINT_LEAK`, `GAS_THRESHOLD`, `IGNITION`) — а в коде **нет** ни одной ссылки на сюжет «пожар в 22:00».
- Грепом по `src/sim` убедиться, что нет `if (pass)…fire()`-подобных связей.

- **Бронза — «Тёмная ночь».** Матвей не открыл вентиль (C без последующего открытия) → фонарей нет, Клара в отчаянии, но все целы.
- **Чёрная — «Пожар».** Огонь, пострадавшие, Пип не выведена. Дальше — «Нить» подсказывает вернуться.
- Для каждой — финальный экран из «Вестника» + «Хроника Окна»: «вот что вы сдвинули».

## 16. Бюджеты и этапы

**Производительность.** Цель 60 fps на встроенной GPU: ≤ 1.2M видимых треугольников, ≤ 400 draw calls, ≤ 12 динамических света, тени — только луна + главный свет интерьера. Модульные здания — InstancedMesh/`mergeGeometries` по типам, LOD по расстоянию туманом (за 60 м — упрощённые силуэты `buildings_hex`).

**Этапы (в порядке работы):**
1. Каркас: Vite+TS, загрузчик ассетов, сцена, пост-обработка (скопируй из `tools/style_test`), фонари, дождь. Сравни с `docs/screenshots/proof_*.png`. **Результат этапа — скриншот.**
2. Мир: площадь, фасады (≥8 разных), набережная, вода, причалы, башня снаружи.
3. NPC: 12 + животные, анимации, ходьба по сетке, расписания.
4. Интерьеры: таверна (зал, кухня, погреб, этаж), мастерская, бюро, будка, башня + Окно.
5. Симуляция: ядро из старой ветки + новые системы (газ, огонь, трамвай, причал, стелс).
6. Диалоги + журнал + хроника + «Вестник».
7. Тесты: determinism, cascade, solve (раздел 11).
8. Полировка: звук, детали, баги.

**Приёмка (acceptance):**
- [ ] Скриншоты площади/набережной/таверны не хуже `docs/screenshots/proof_*`.
- [ ] Все интерьеры входимы без загрузки; все объекты из таблиц раздела 5 интерактивны.
- [ ] Трамвай ездит, проездной проверяется.
- [ ] `npm run sim:solve` — зелёный (≥3 прыжка, ≥2 решения).
- [ ] `npm run sim:cascade` — зелёный.
- [ ] `npm run sim:hash` — детерминизм на 20 сидов.
- [ ] Ru/En полностью, без пропущенных ключей.
- [ ] Доска «Вестник» отражает состояние мира (3 разных заголовка минимум).
