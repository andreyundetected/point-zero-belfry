# Что упрощено относительно спеки (и почему)

| Пункт спеки | Что сделано | Почему |
|---|---|---|
| §6.1 лестница башни | затемнение + 60 игровых секунд, без физической винтовой лестницы | спека допускает «сменяющиеся пролёты с затемнением» |
| §6.6 приют | 1-й этаж (холл, кабинет), 2-й (спальня, 14 коек); 3-й этаж и часовня не входимы | 9 входимых мест из §5.3 это не требует |
| §6.8 баржа | палуба, рубка, люк; **трюм не входим** (виден люк) | цена/выгода; детские туфли — только в описании |
| §6.9 катер | рубка + корма как один подвижный меш; каюта Харроу — рубка | движущаяся платформа без физики, игрок стоит у штурвала |
| §3.2 дым и огонь | процедурные языки пламени (шейдер), искры (Points), дым подсвечен снизу; горящие оконные рамы приближены пламенем вдоль фасада, а не отдельными окнами; свет в пуле ≤ 10 динамических | бюджет света §15.4 |
| §14 звук | дождь/ветер/огонь/мотор — синтез WebAudio; шаги, двери, прыжок, выстрел — из пака | музыки нет по спеке |
| §8.8 свет как укрытие | видимость = освещённость точки (лампы, окна, огонь) × движение; конус 50°, дальность 4–14 м | как в спеке, без сложного ИИ |
| §8.5 маскировка | проверка у пристани №3: кепка/«Я»/список; проверка «лицо в свету >2 с» не реализована | диалог §14.2 |
| §8.4 чека | выбивается за 3 игровые секунды, если охрана не смотрит (22:15–22:38); колесо отваливается в 22:44 на мосту, повозка наклоняется, Анна уводит детей как флаг | без отдельной сцены |
| Английский | интерфейс и ключевые реплики; остальные реплики падают на русский | ключи едины, перевод дописывается |
| Окна с силуэтами за шторой | не сделаны | декор |
| Прохожие | 8 городских + 4 посетителя; не реагируют на пожар | бюджет людей (≤18 в сцене) |
| Повозка/катер/машины | код-примитивы (лошадь — силуэт), машины — `city_bits/car_sedan` | KayKit/Kenney запрещены для домов, не для машин |
| §13.3 «Верю» | диалог, удар Створкой, экран «Утро» с фактами; перестрелки на пирсе, горящие бочки и таймер 60 с «дети бегут на катер» не сделаны (число спасённых считается по флагам) | цена/выгода, остальные механики приоритетнее |
| §8.3 патруль на мосту | два патрульных на западном въезде с 22:18 (если `tapCut`), невидимый барьер, пропуск — жетон №17 | как в спеке, без погони |
| §6.5 состояния конторы | сейф и Гейл меняются по флагам (взрыв/налёт/предупреждён); внутренность конторы визуально не «разворочена» | декор |
| Звук | нет музыки (по спеке); колокол — только расписание событий без звука | нет времени на сэмплы колокола |
| Плейтест ч.1, предпросмотр и закладки | убраны из интерфейса (по правкам H); код предпросмотра остался неиспользуемым | шкала и так показывает известные события ⟲ |
| Плейтест ч.1, D4 взрыв | вспышка, столб огня и дым видны над крышами с моста; прямой улицы до склада нет | склад стоит за кварталом, геометрию карты не меняли |
| Плейтест ч.1, люди на карте | показано, где игрок видел человека последний раз, а не где он сейчас | честная информация: знания, а не всевидение |
| Плейтест ч.1, NPC «наверстывает» | после разговора NPC идёт по расписанию с текущей точки; если опоздал, срезает время ожидания, но не телепортируется | без отдельной логики «догона» |
| Плейтест ч.1, анимация прыжка Неда | Нед подходит к перилам, переходит через них и падает по прямой в воду (−4.6), всплеск; отдельной анимации «перелезания» в паке нет | клипы пака: walk/idle/jump |
| Реакции прохожих | одна реплика при столкновении (по часу ночи), поворот головы; уклонения в сторону нет | расписания детерминированы, обход игрока сломал бы хэш-тесты |
| Деревья | тёмные силуэты низкополигональных деревьев пака | в паке нет голых осенних деревьев |
