# 04 · Стартовый промпт для облачной сессии (вставь целиком)

```
Ты — старший инженер-геймдев (TypeScript / Three.js / Vite). Репозиторий point-zero-belfry, ветка v3/zaton.
В ветке уже лежит пак: /assets, /docs, /tools, CREDITS.md. Старого кода игры в рабочем дереве нет (он в истории git, смотреть не нужно).

ЦЕЛЬ
Собрать с нуля игру «Окно»: одна ночь в районе Затон, 1947 год, вид от первого лица, устройство «Створка»
для прыжков во времени внутри часа 22:00–23:00, в любой момент и из любого места, прыжок — на месте.
Сюжет, мир, механики, хронология, эталонное прохождение: docs/01_GAME_SPEC.md (единственный источник правды).
Все диалоги: docs/02_DIALOGUES.md (переносить полностью, по-русски как написано; английский перевод сделай сам, коротко и разговорно).
Ассеты и как их грузить: docs/03_ASSET_GUIDE.md. Проверенный рецепт картинки: tools/style_test/noir.html
(процедурные дома с PBR-текстурами, красный акцент по цвету материала, 20% цвета, неровная земля, свет, дождь, Створка в руке; люди — ?people=1, с известной проблемой масштаба). Эталон картинки: docs/screenshots/style_v4_street.png.

ЖЁСТКИЕ ПРАВИЛА
1. Только первое лицо. Никакой изометрии, вида сверху, третьего лица.
2. Каждый прыжок мотивирован историей. Нить на Створке и красный маркер на карте всегда показывают, куда идти.
3. Картинка: 20% цвета, красный — только у важного (настоящий красный материал, без наложений). Правила красивого города — спека §3.6, обязательны для каждого кадра.
4. Земля неровная: всё ставится на groundH(x,z), включая NPC и игрока.
5. Город расставлен по разделам 4–5 спеки, не случайно. Единственная переправа — Старый мост.
6. Дома — только процедурный генератор (§3.4), не Kenney/KayKit. Люди — тела people/mixamo + одежда-оболочка кодом + ретаргет UAL (§3.5). Сначала почини масштаб людей (§3.5).
7. Симуляция: src/sim — чистый TS без THREE, без Math.random/Date.now. NPC = расписания + флаги причин. Никаких сложных систем.
8. Никакого LLM в игре. Ru/En, все строки — ключи.
9. Диалоги начинаются с начала (реакция на появление Тика), ветки давления знанием помечены «⟲ время» и видны только при наличии знания.
10. Мало кода. Если пункт спеки дорогой — упрости и запиши в docs/DEVIATIONS.md, не молча.
11. Ассеты только из /assets. Если чего-то нет — собери кодом из кусков пака. Сеть наружу, кроме GitHub и npm, закрыта.

ПОРЯДОК (после каждого этапа — commit и push)
1. Каркас: Vite+TS, загрузчик, рецепт картинки из noir.html, контроллер от первого лица, Створка в руке. Скриншот.
2. Мир: terrain (groundH), канал, Старый мост, улицы, генератор домов (≥10 разных), ≥18 закрытых домов, плотность и мелочь по §3.6 и §5.1, пирсы. 5 контрольных скриншотов (§3.6.12).
3. Входимые места (9 штук, §5.3, §6), бесшовно, со своим светом.
4. Люди: тела Mixamo + одежда-оболочка + шляпы, масштаб, ретаргет UAL, расписания всех NPC по §10.
5. Время и Створка: ×4, ожидание, шкала, предпросмотр, прыжок на месте, Карман, журнал с портретами, Нить, карта с метками, вкладка «Эта ветка».
6. Диалоги (весь 02_DIALOGUES.md) + сцены NPC↔NPC субтитрами в мире + голос Тика.
7. Механики §8: Фома через время, кража жетона, подвал башни (флаг tapCut и его последствия), чека повозки, маскировка, катер, разговор под прицелом, свет как укрытие, стрельба.
8. Финал §13 и финальный экран. Пожары и поломки города по хронологии.
9. Тесты: sim:baseline (хронология без игрока), sim:solve (эталон §11 по записанному списку действий), sim:hash (детерминизм).
10. Полировка: звук §14, мелочь на земле, бельё, вывески.

СКРИНШОТЫ
Только после этапов 1, 2, 4 и 8: tools/shot.cjs (Playwright + chromium с флагами --use-angle=swiftshader --enable-unsafe-swiftshader),
положить в docs/screenshots/progress_*.png. Больше не гонять — у пользователя ограниченный лимит.

РАБОТАЙ АВТОНОМНО
Не задавай вопросов. Решения — в docs/DECISIONS.md. Застрял на одном элементе дольше 20 минут — упрости и иди дальше.
В конце: что работает, что упрощено, как запустить (npm i && npm run dev), как прогнать тесты.
```

- Первая проверка — скриншот этапа 1. Если не похоже на `style_v4_street.png`, останови и попроси поправить картинку до продолжения

- Если люди выглядят огромными или проваливаются — это масштаб Armature 0.01, см. спеку §3.5
