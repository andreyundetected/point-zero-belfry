# Окно: Затон

Ночь 1947 года. Один час — с 22:00 до 23:00 — и устройство в левой руке.
Каждый прыжок создаёт новый мир; смерть окончательна.

Three.js + TypeScript + Vite, вид от первого лица.

## Запуск

```bash
npm ci
npm run dev        # http://localhost:3000
```

Ассеты лежат в `assets/` и отдаются как корень (`/models/...`, `/textures/...`, `/hdri/...`).

## Управление

| Клавиши | Действие |
| --- | --- |
| WASD | идти |
| Shift | бежать |
| мышь | смотреть (клик по сцене захватывает курсор) |
| E | говорить / взять / использовать / открыть дверь |
| Tab | Створка: время, нить, люди, карта, карман, сообщения |
| ЛКМ | выстрел (если есть револьвер) |
| T | ждать (время идёт в 4 раза быстрее; в бою недоступно) |
| B | закладка на текущей минуте |
| F | русский / английский |
| Esc | закрыть Створку |

В Створке время выбирается кликом по шкале, кнопками минут или закладкой.
Прыжок — кнопка «Прыгнуть»; удержание показывает предпросмотр минуты,
отпускание подтверждает. Прыжок невозможен, если в выбранной минуте на вашем
месте стена.

## Проверки

```bash
npm run typecheck
npm test                 # 11 тестов sim: расписания, хронология, прыжок, детерминизм
npm run sim:baseline     # хронология без игрока
npm run sim:solve        # эталонное прохождение
npm run sim:hash         # одинаковый хэш на 10 сидах
npm run build
```

`src/sim` — чистый TypeScript без THREE, `Math.random` и `Date.now`.

## Структура

```
src/sim/        чистая симуляция: время, знания, флаги, расписания
src/content/    места, расписания NPC, диалоги, i18n
src/world/      террейн, дома, город, люди
src/render/     рендер, материалы, пост-обработка
src/game/       игрок и игровой цикл
src/ui/         HUD, Створка, диалоги, экраны
tools/          базлайн, солвер, хэш, скриншоты
tests/          тесты симуляции
docs/           спецификация, диалоги, гайд ассетов, отклонения
```

Осознанные упрощения перечислены в [docs/DEVIATIONS.md](docs/DEVIATIONS.md).
