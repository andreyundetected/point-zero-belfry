# Окно — Затон, 1947

Стелс-детектив с прыжками во времени, вид от первого лица. Одна ночь, окно 22:00–23:00, устройство «Створка».
Спека — `docs/01_GAME_SPEC.md`, диалоги — `docs/02_DIALOGUES.md`, решения и упрощения — `docs/DECISIONS.md`, `docs/DEVIATIONS.md`.

## Запуск

```bash
npm i
npm run dev        # http://localhost:5173
```

Игра открывается главным меню: «Новая игра», «Продолжить» (один слот автосохранения: после прыжков, разговоров и каждые 20 с), настройки (качество, мышь, громкость, поле зрения, язык), управление. `Esc` в игре — пауза. Клик по экрану — захват мыши.

| Клавиша | Действие |
|---|---|
| WASD | ходить |
| Shift | бег |
| Пробел | **прыжок** |
| C / Ctrl | присесть |
| E | действие (двери, предметы, разговор) |
| Tab | Створка: время (шкала, прыжок) |
| M / J / I | карта / люди / карман |
| N | текущая нить на экране |
| Enter (в Створке) | прыжок во времени на выбранную минуту |
| Esc | меню/пауза, закрыть Створку, уйти из разговора |
| T (зажать) | ждать, время ×16 (песочные часы; движение отменяет) |
| 1 / 2 | достать револьвер / убрать (после находки) |
| ПКМ / ЛКМ / R | прицел / выстрел / перезарядка |
| 1–9, ↑↓ + Enter, мышь | выбор реплики в разговоре |
| F3 | каркасы коллайдеров (отладка) |

Отладка: `/?at=x,z,lookX,lookZ&t=мм:сс&y=roof&noprologue=1` — встать в точку на заданной минуте.

## Тесты

```bash
npm run check            # tsc + npm test + браузерная проверка коллизий, дверей, маршрута
npm test                 # sim:baseline + sim:solve + sim:hash + диалоги + скорости + сценарии (чистая симуляция, tsx)
npm run sim:baseline     # хронология ночи без игрока + проверка, что никто не уходит за карту
npm run sim:solve        # эталонное прохождение по спеке §11 (≥9 прыжков), 35 проверок
npm run sim:hash         # детерминизм на 10 сидах
npm run test:world       # браузерные проверки (Playwright): меню и сохранение, хитбоксы и прыжок, загрузка, пролог, Фома, две цепочки сюжета, бой
```

## Структура

```
src/sim      чистый TS (без THREE, без Math.random/Date.now): время, флаги, расписания NPC, хронология, состояние города
src/world    карта, рельеф groundH, коллайдеры, генератор домов, интерьеры, башня, руины, канал/мост/пирсы, декор и уличные мелочи (dressing)
src/render   материалы (погода на стенах, атлас окон), пост-обработка, атмосфера, погодные эффекты
src/game     игрок + физика, Створка, меню и настройки, сохранение, диалоги, люди, бой, катер, HUD, звук
src/content  диалоги (02_DIALOGUES.md целиком), нити, мир-предметы, сцены NPC↔NPC
tests        sim:baseline / sim:solve / sim:hash
tools        shot.cjs (скриншоты), test_*.cjs (браузерные тесты)
```

Хитбоксы: любой твёрдый предмет — повёрнутый бокс с вертикальным диапазоном; регистрируется тем же кодом, что строит геометрию
(`src/world/colliders.ts`). Игрок: радиус 0.32, рост 1.75, ступенька 0.42 м, прыжок 0.86 м; ограды и парапеты имеют коллайдер 1.45 м.

## Быстрее: десктопная версия (Electron)

```bash
npm i -D electron @electron/packager     # один раз
npm run desktop                          # собрать и запустить в своём окне, на видеокарте, без лимита кадров, F11 — окно/полный экран
npm run desktop:pack                     # папка release/okno-win32-x64 с .exe, можно отдать как есть
```

Играть можно и в браузере: `npm run build && npx vite preview`. Для слабых машин `?scale=0.7` задаёт внутреннее разрешение (по умолчанию подбирается само по кадрам).
