# «Окно» — Часовая набережная

Мини-уровень игры «Окно»: одна дождливая ночь, одна набережная, 40 игровых минут (21:20 → 22:00). Мир живёт по правилам: из потерянного проездного швеи Тильды вырастает пожар в таверне «Три якоря» — цепочка **нигде не прописана**, она получается из общих правил симуляции. Игрок может сдвинуть ночь через **Окно** (перемещения во времени, перенос одного предмета и знаний).

- Источник правды: `docs/01_LEVEL_SPEC.md` · ассеты: `docs/02_ASSET_GUIDE.md` · решения: `docs/DECISIONS.md` · отклонения: `docs/DEVIATIONS.md`.
- Стек: TypeScript, Three.js 0.170, Vite. Симуляция (`src/sim`) — чистый TS без Three/`Math.random`/`Date.now`.

## Запуск
```bash
npm i && npm run dev        # http://localhost:5173
npm run build               # tsc + vite build (assets копируются в dist/assets)
```
`/assets` раздаётся как статика (плагин `serve-assets` в `vite.config.ts`).

## Управление
`WASD` — ходьба · `Shift` — бег · `C` — красться · `E/F/G` — действия с подсказки · `X` — положить предмет · `Q` — Журнал/Хроника · `Tab` — ускорить время (×16) · мышь — камера (перетаскивание), колесо — дистанция. Язык (Ru/En) — на титульном экране.

**Первые минуты (урок ключа):** выйдите из башни, у будки Игната узнайте, что он уходит на чай в 21:36, заберите ключ с крюка, вернитесь к Окну (кресло наверху башни) и прыгните на T0 — ключ вернётся с вами (мерцающим двойником, пока оригинал существует). Затем откройте шкаф КШ-1.

## Тесты
```bash
npm test               # vitest: детерминизм, каскад, солвер, «Вестник», локализация Ru/En
npm run sim:hash       # детерминизм: 20 сидов × 2 прогона, хэш каждые 4 игровых секунды + запись→воспроизведение
npm run sim:cascade    # каскад «проездной → пожар» из общих правил + grep по src/sim на запрещённые связки
npm run sim:solve      # солвер: классы решений A/B/C, минимум прыжков (JSON-отчёт и хэши)
npm run typecheck      # tsc --noEmit
```
`sim:solve` (seed 1): классы **A** «стравить давление», **B** «билет Тильде», **C** «буквальный приказ + вентиль таверны»; кратчайшее решение **3 прыжка** (урок ключа → наблюдение до T1 → перенос предмета), все исходы ≠ пожар. Подробности и честная оговорка про «физический минимум = 2» — в `docs/DEVIATIONS.md`.

## Структура
```
src/sim/      чистая симуляция: map (граф), world (тик), npcs, systems (трамвай, причал, газ, огонь), dialog(+Data), session (ветка, Окно), solver, plans, chronicle, news
src/render/   Three.js: engine, post, atmosphere (свет, дождь, вода, фонари), kit (сборка зданий из town_kit), facades (таблица фасадов), town, interiors, actors, fx
src/game.ts   игровой цикл, ввод, взаимодействие, диалоги, Окно, Журнал
src/ui/       DOM-интерфейс; src/data/ — тексты Ru/En (UI, предметы, барки); src/audio.ts — WebAudio
tools/        shot.mjs (скриншот через Playwright+SwiftShader), sim_* (тесты), smoke*.mjs (браузерный дымовой тест)
docs/screenshots/progress_*.png   скриншоты этапов 1 и 4
```
